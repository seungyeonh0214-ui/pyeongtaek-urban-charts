# 고덕동 · 진위면 비교 — 평택시 도시계획시설

브이월드 2D 데이터 API 2.0으로 받은 평택시 레이어를 카탈로그 행 기준으로 집계해 그린 정적 페이지.
6주차 과제 후보지 두 곳을 같은 기준으로 견준다.

- 좌우 대비 막대 — 10개 항목을 가운데 축 기준으로 1번(고덕동)·2번(진위면)으로 나눠 표시
- 차트 A (막대, 비교 필수) — 공원 유형별 건수, 도로 위계별 연장. 두 지역이 같은 눈금을 쓴다
- 차트 B (도넛, 구성비 선택) — 도시계획시설 대분류 구성비
- 지도 — 공원 분포. 두 지역은 축척이 달라 각 지도에 축척 막대를 넣었다

모든 차트가 제목 · 축(기준) · 단위 · 출처 · 조회일 · 강조 여섯 요소를 갖췄다.

## 배포

정적 파일 하나(`index.html`)뿐이라 빌드 설정이 필요 없다.
`main` 브랜치에 push하면 Vercel이 production으로 자동 배포한다.

## 인증키

인증키는 환경변수 `VWORLD_KEY`로만 주입하며 이 저장소에는 들어 있지 않다.
값은 수집 단계에서 이미 집계된 결과이고, 이 페이지는 API를 호출하지 않는다.
